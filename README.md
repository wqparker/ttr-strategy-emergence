# ttr-strategy-emergence

A personal project using the board game Ticket to Ride as a base to explore and touch-up skills in Python, machine learning, and data analysis.

Though I would rather do a larger share of the work strictly myself, I am deciding to prioritize execising practice of agentic coding for this project this time around. 

The game is recreated as a multi-agent reinforcement learning environment. Agents are trained on it to see which strategies emerge, for example blocking opponents vs. hoarding routes, or long risky routes vs. short safe ones.

See [PLAN.md](PLAN.md) for the roadmap and design decisions.
